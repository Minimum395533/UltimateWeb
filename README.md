# UltimateWeb

UltimateWeb is a browser-based, Smash-inspired game interface prototype built with React, TypeScript, and Vite.

## Run the project

```sh
npm ci
npm run dev
```

The Vite development server listens on port `5000` and is configured for Replit's proxied preview.

## Project guide

See [`MISTRAL.md`](./MISTRAL.md) for the environment setup, app structure, routes, current feature limits, and guidance for coding assistants.
